\begin{abstract}
We propose \sysname, a topology-aware graph contrastive learning framework for label-efficient intrusion detection. \sysname learns representations from normal system-activity graphs using unsupervised contrastive learning and incorporates topological structural information to capture graph patterns. Unlike generic graph contrastive learning methods that are designed primarily for representation learning or graph classification, \sysname is designed for intrusion detection through anomaly scoring. It computes detection scores in the same projected contrastive embedding space optimized during training, reducing the mismatch between representation learning and anomaly detection. During inference, each test graph is scored by its distance from the learned distribution of graph embeddings, with larger distances indicating higher anomaly likelihood.

We evaluate \sysname on StreamSpot, GraSec-IoT, and Unicorn against a supervised graph neural network and GraphCL, a unsupervised graph contrastive learning baseline. The supervised model performs strongly when labeled attack examples are available, but \sysname achieves the best performance among unsupervised detection methods. Compared with GraphCL, \sysname improves F1 score from 0.923 to 0.926 on StreamSpot, from 0.790 to 0.985 on GraSec-IoT, and from 0.583 to 0.863 on Unicorn Wget. These results show that combining topological structure with contrastive graph representation learning can improve intrusion detection under limited attack-label availability.
\end{abstract}
