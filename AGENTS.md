# Repository Instructions

This repository contains both experimental code and a research paper.

## Paper
The LaTeX manuscript is located in `/paper`.

## Experimental results
Final experimental outputs are stored in `/results`.

## Code
Training and evaluation scripts are stored in `/scripts`.

## Rules
- Never change experimental results manually.
- Do not invent numerical results.
- Verify claims in the paper against `/results`.
- Preserve LaTeX citations, labels, and references.
- Do not modify code when asked to edit the paper unless explicitly instructed.
- Do not modify files outside `/paper` during manuscript editing tasks.
- Keep terminology consistent: the proposed method is TRACE.
